# Code Coverage

## Prerequisites

Requires **PCOV** or **Xdebug** loaded in the CLI binary — no built-in coverage otherwise. If you see "no code coverage driver available," check `php -m` for one of these. Xdebug additionally needs its coverage mode enabled (`xdebug.mode=coverage` or `XDEBUG_MODE=coverage`).

- **PCOV**: line coverage only, fast.
- **Xdebug**: line, branch, and path coverage (`--path-coverage` / `pathCoverage="true"`), slower.

## Scoping what's measured

Configure via `<source>` in `phpunit.xml` (see `configuration-files.md`) or `--coverage-filter <dir>` on the CLI. `includeUncoveredFiles` (default `true`) reports every included file even if never executed — keep this on for an honest picture of untested code; setting it `false` only reports files that were actually hit.

## Attributes for scoping coverage per test

```php
#[CoversClass(Calculator::class)]
#[CoversMethod(Calculator::class, 'add')]
#[UsesClass(Formatter::class)]   // expected collaborator, won't be flagged risky
final class CalculatorTest extends TestCase { /* ... */ }

#[CoversNothing]                  // e.g. an integration test — excluded from coverage entirely
final class IntegrationTest extends TestCase { /* ... */ }
```

Also available: `#[CoversFunction]`, `#[CoversTrait]`, `#[CoversNamespace]`, and the `Uses*` counterparts. Parent classes are auto-included when using `CoversClass`/`UsesClass`.

## Ignoring code blocks in production source

```php
exit; // @codeCoverageIgnore

// @codeCoverageIgnoreStart
unreachable_code();
// @codeCoverageIgnoreEnd
```

`--disable-coverage-ignore` (CLI) / `disableCodeCoverageIgnore="true"` (XML) forces these to be measured anyway.

## Generating reports

```bash
./vendor/bin/phpunit --coverage-html build/coverage-html
./vendor/bin/phpunit --coverage-clover build/clover.xml
./vendor/bin/phpunit --coverage-text
```

Formats: HTML, Clover, OpenClover, Cobertura, Crap4J, PHPUnit's own XML/PHP-serialized formats, and plain text (`--only-summary-for-coverage-text` for just the summary).

## Gotchas in PHPUnit 12

- `match` expression arms report coverage unreliably — both PCOV and Xdebug can show the whole `match` block as covered even when some arms were never executed. Don't trust match-arm-level coverage; verify with explicit tests instead.
- Coverage reflects **bytecode execution**, not literal source lines — `opcache.optimization_level` can change generated bytecode for identical source, which is a known source of coverage/source mapping mismatches.
- `--warm-coverage-cache` pre-analyzes source ahead of a run to speed up large suites.
